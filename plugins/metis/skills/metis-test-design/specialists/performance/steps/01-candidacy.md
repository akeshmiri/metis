# 1 · Candidacy, and the refusal

## Actions

1. `design_report(journey, surface, section="performance")`.
2. Report the three verdict counts. If `no-basis` dominates, say so as the
   headline: **the model was not sized**, which is a finding about the model.
3. Ask for `nfr_targets` using the wording in `design_inputs`. "Name a number or
   say there is none" — both are answers.
4. `describe_execution` before proposing anything be run. At tier `off` nothing
   can be driven, and that is the default.

## Forbidden substitutions

- Do not convert a risk band into a load target. A band ranks what there is to
  get wrong; it says nothing about volume.
- Do not propose a load test for a call with no target. There is nothing for it
  to fail.

## Report

Verdict counts, the recovered basis behind each candidate, and whether anybody
has stated a target.
