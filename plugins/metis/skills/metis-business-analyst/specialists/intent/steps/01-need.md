# 1 · Is there a need here?

## Actions

1. `check_intent(document_json)`. Every problem it names is blocking, because
   `metis intent land` refuses the file over any of them — one definition, not
   two.
2. Read each statement as written. **Never paraphrase**: a reworded need is a
   different claim, and the id digests the text precisely so that is visible.
3. `search_knowledge` for a claim that already says this, or says the opposite.
   Two intents for one need is how a graph starts disagreeing with itself.

## Three problems that look alike and are not

| Problem | Means |
|---|---|
| no statement | there are no words. Not vague — absent |
| vague statement | there are words, and two readers would act differently |
| no specification | the need is clear and nobody has said how it behaves |

Only the first and third are about the need. The second is the requirement
reading's business — route it to `metis-knowledge-capture`.
