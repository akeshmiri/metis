# 01 — build the document

## Actions

1. Confirm the model is approved. The workflow's precondition enforces it;
   report the count rather than the conclusion.
2. Build the specification and render it.
3. Plan the write against the target repository and read the plan out: what
   would be written, and what is withheld and why.

## Forbidden substitutions

- Do not write prose the model does not support to fill a thin section (SP-1).
- Do not resolve a conflict between the model and an existing file by preferring
  one. Preserve it and report it.

## Drift check

Every section of the document should trace to the model. A section that does not
came from somewhere, and that somewhere is not evidence.

## Report

The feature, the destination path, what would be written, what is withheld.
