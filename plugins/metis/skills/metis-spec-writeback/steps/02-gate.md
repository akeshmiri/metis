# 02 — the write-back gate

## Actions

1. Show the plan in full — destinations and withholdings — before asking.
2. State both keys: whether the literal has been given, and whether the
   installation permits external writes.
3. Ask once. The default is No.
4. On a literal `publish` with the installation switch set, apply. Otherwise stop
   and say which key was missing.

## Forbidden substitutions

- Do not supply the literal yourself, including when the user has said to go
  ahead in general terms. The word is theirs, in this run.
- Do not set or suggest setting the installation switch as part of the run. It
  is a deployment decision somebody makes deliberately, not a step in a task.

## Drift check

The plan applied must be the plan shown. If the model or the target changed in
between, re-plan and ask again.

## Report

Files written, files withheld and why, and — plainly — whether anything was
written at all.
